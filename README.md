# پروژه درس آمار - پاییز ۱۴۰۵
**عنوان:** بررسی رابطه فعالیت بدنی و سلامت روان در NHANES 2021-2023  
**مسیر انتخابی:** مسیر الف (NHANES 2021-2023)  

این مخزن شامل تمام کدها، گزارش‌ها و اسکریپت‌های مربوط به ۵ فاز پروژه درس آمار است.

## ساختار مخزن
- `data/`: شامل توضیحات داده‌ها و فایل‌های خام (به دلیل حجم بالا فایل‌های داده در گیت آپلود نمی‌شوند).
- `notebooks/`: نوت‌بوک‌های تحلیلی پایتون برای هر فاز.
- `reports/`: گزارش‌های مکتوب نهایی در قالب فایل PDF.
- `figures/`: نمودارهای تولید شده در مراحل مختلف تحلیل.
- `PROJECT_CARD.md`: شناسنامه و کارت مشخصات سؤال آماری و متغیرها.
